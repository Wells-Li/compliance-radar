# 合规雷达 · Compliance Radar

面向**做 AI 应用的中国团队**的规则变更周报。只回答一个问题：

> **这一周有哪些新规则会让你上不了架、被下架或被罚？你要改什么？什么时候之前？**

不做法律分析（律所有资质、我没有）。只做工程可执行的部分：**条款变了什么 → 命中哪类 App → 你要改哪个模块 → 截止日是哪天**。

## 三条硬纪律

1. **只有一手来源能进正文。** 二手线索一律进「本期未核实」，并注明待核实动作。一份把传闻当事实的周报，错一次就死了。
2. **不提供任何规避审核的方法。** 苹果 Guidelines 2.5.19 已把隐藏功能与代码混淆列为**终止开发者账号**的理由。帮人绕审核等于帮人自杀。
3. **不预测。** 只报已发布的规则与已发生的事件。

每期页脚固定声明：本文是工程视角的规则变更整理，**不构成法律意见**。

## 目录

```
issues/          每期期刊，YYYY-WW.md
state/           last_seen.json —— 已见条目指纹，用于跨期去重
metrics/         YYYY-WW.csv —— 每期可观测指标（访问、star、订阅）
pipeline.md      自动化流水线的定义文档（cron 任务按此执行）
```

## 监测信源

**一手（必须直接抓取）**

- Apple Developer News — <https://developer.apple.com/news/>
- App Review Guidelines — <https://developer.apple.com/app-store/review/guidelines/>
- Google Play 政策更新与 Play Console 公告
- 国家网信办 算法备案 / 生成式 AI 服务备案公示
- 广电总局 微短剧与网络视听通知
- 国家标准全文公开系统

**成本情报（次要版块）**：主流模型 API 牌价、GPU 租赁价格、主要推理框架版本。只报变动，不评论。

## 自动化

本仓库由两个定时任务驱动：

| 任务 | 位置 | 时间 | 职责 |
|---|---|---|---|
| 采集 | 云端 | 每周一 08:00 (Asia/Shanghai) | 抓一手信源，产出本期变更草稿 |
| 发布 | 本地 | 每周二 10:00 (Asia/Shanghai) | 去重、成稿、写 `issues/`、更新 `state/`、`git push`、记录指标 |

本地任务**自足**：若云端草稿不可读，它自己完成采集。云端是保险与加速，不是单点依赖。
